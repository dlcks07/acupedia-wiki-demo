문단 편집 · [[위키링크]] 데모

작성자가 H2/H3 제목만 넣으면 시스템이 문단·목차·편집 버튼을 자동 생성합니다. 아래는 교수님께 흐름을 보여드리기 위한 테스트 화면입니다.

[[ ]] 위키링크 테스트용 더미 항목

이 페이지에는 실제 Acupedia DB가 연결되어 있지 않고, 아래 항목만 자동완성 검색 결과로 제공됩니다. 위키와 학술자료고에 같은 이름이 있는 경우(예: 합곡, 경근) 자동완성에서 구분되어 표시됩니다.

위키 더미 항목

합곡 태충 족삼리 경근 경혈

학술자료고 더미 항목

합곡 내관 수삼리 풍지 경근 경락 팔맥교회혈
  1. 아래 본문에서 원하는 문단 옆 [편집]을 누릅니다.
  2. 편집창에 [[를 입력한 뒤 글자를 이어 씁니다. (예: [[합, [[경, [[팔)
  3. 자동완성 목록에서 [위키] 또는 [학술자료고]로 구분된 항목을 선택합니다.
  4. 선택하면 [[문서명]]이 아니라 data-wiki-id / data-archive-id가 붙은 내부 링크 HTML이 삽입됩니다.
  5. 이 문단 저장을 누르면 해당 문단에만 링크가 반영됩니다.
1. 문단 자동 인식 제목 스타일(H2/H3) → 번호·목차·앵커·문단별 [편집]이 한 구조로 생성됩니다.
2. 문단만 편집 [편집]을 누르면 해당 문단만 TinyMCE로 열어 수정하고 저장합니다.
3. [[ ]] 내부 링크 편집 중 [[ 입력 시 위키 / 학술자료고를 구분해 자동완성합니다.

아래 본문은 데모용 샘플입니다. 각 제목 옆 [편집]을 눌러 해당 문단만 수정해 보세요. 편집창에서 [[를 입력하면 위키·학술자료고 자동완성이 나타납니다.

데모에서 확인해 보실 점

  • 왼쪽 목차 클릭 → 해당 문단으로 이동 (나무위키식 앵커)
  • 문단 [편집] → 해당 구간만 수정 (전체 문서를 다시 열지 않음)
  • 편집기에서 [[합, [[경, [[팔 입력 → 위키 / 학술자료고 구분 자동완성
  • 저장 시 [[문서명]]이 아니라 data-wiki-id / data-archive-id가 붙은 HTML 링크로 저장되는 구조를 가정합니다
문단 편집
위키링크 테스트: [[를 입력한 뒤 글자를 치면 자동완성이 열립니다. [위키] = 위키 더미(합곡·태충·족삼리·경근·경혈), [학술자료고] = 학술자료고 더미(합곡·내관·수삼리·풍지·경근·경락·팔맥교회혈). 항목을 선택하면 내부 링크 HTML이 삽입됩니다.
